# 🤖 بوت تليجرام متتبع الدعاوى المدنية - منصة مصر الرقمية

بوت تليجرام ذكي ومخصص للمحامين لمتابعة قضايا ودعاوى منصة مصر الرقمية مباشرة من الهاتف المحمول، مع إمكانية تجديد التوكن بضغطة زر وتلقي إشعارات فورية عند تغيير حالة أي طلب.

---

## 🚀 مميزات البوت:
1. **📋 عرض ومتابعة الطلبات:** استعراض كافة القضايا مع حالاتها وأكوادها وتصنيفاتها.
2. **⚡ تحديث فوري:** فحص حالة الدعاوى الحالية من منصة مصر الرقمية بضغطة زر.
3. **🔑 تجديد التوكن بضغطة زر:** يقوم البوت بتشغيل الدخول الآلي بالخلفية وتحديث الجلسة وملف `token.text` فوراً.
4. **💳 أرقام سداد الرسوم:** حصر القضايا التي تم تقدير رسومها لعرض كود السداد البنكي بسهولة.
5. **🔔 إشعارات دورية تلقائية:** فحص آلي في الخلفية (كل 10 دقائق مثلاً) وإرسال تنبيه فوري لهاتفك بمجرد تغير حالة أي قضية (تقدير رسوم، سداد، قيد جدول المحكمة، إلخ).
6. **🔍 بحث ذكي:** ابحث برقم الطلب أو اسم الموكل أو رقم السداد.
7. **👤 تسمية الموكلين:** ربط اسم الموكل بالطلب مباشرة من خلال الأمر `/name <رقم_الطلب> <اسم_الموكل>`.

---

## 🛠️ خطوات التشغيل لأول مرة (في دقيقة واحدة):

### 1. إنشاء البوت والحصول على التوكن (Bot Token):
1. افتح تطبيق تليجرام وابحث عن الحساب الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل له الأمر: `/newbot`.
3. اختر اسماً للبوت (مثال: `متتبع قضايا مكتبي`).
4. اختر اسم مستخدم ينتهي بكلمة `bot` (مثال: `MyLawCaseTrackerBot`).
5. سيعطيك BotFather رمز التوكن (يبدو مثل: `7123456789:AAFn...`). قم بنسخه.

---

### 2. وضع التوكن في الإعدادات:
افتح الملف [`bot_config.json`](bot_config.json) وضع التوكن الذي نسخته في حقل `bot_token`:
```json
{
  "bot_token": "ضع_التوكن_الذي_نسخته_هنا",
  "allowed_chat_ids": [],
  "auto_check_interval_minutes": 10,
  "auto_notify_enabled": true
}
```

---

### 3. تشغيل البوت:
- يكفيك **النقر المزدوج على ملف:** [`run_bot.bat`](run_bot.bat)
- أو تشغيله عبر الطرفية (CMD / PowerShell):
  ```bash
  python bot.py
  ```

---

### 4. بدء الاستخدام:
1. ادخل إلى البوت الخاص بك على تليجرام واضغط **`بدء` (Start)** أو أرسل `/start`.
2. سيتعرف البوت عليك تلقائياً ويسجل حسابك كمدير مصرح له بالوصول.
3. ستظهر لك قائمة الأزرار الرئيسية التفاعلية باللغة العربية لمتابعة كافة قضاياك.
