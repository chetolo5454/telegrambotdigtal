# متتبع الدعاوى المدنية - منصة مصر الرقمية (نسخة بايثون)
### بديل وحيد ومتكامل لإضافة المتصفح (Chrome/Edge Extension)

أداة بايثون متطورة ومكتملة المزايا لمتابعة وتتبع قضايا ودعاوى المحاكم على بوابة **مصر الرقمية (Digital Egypt)** مع واجهة ويب حديثة (Web Dashboard) وأوامر سطرية (CLI)، وحفظ أسماء الموكلين محلياً، وتوليد ملفات الأدلة الرقمية، وتنبيهات ويندوز التلقائية عند تغير حالة أي دعوى أو أرقام سدادها.

---

## 🚀 التشغيل السريع

### 1. عبر النقر المزدوج (Windows):
قم بالنقر المزدوج على ملف:
```
run_tracker.bat
```
سيفتح لك واجهة الويب مباشرة في المتصفح على العنوان: `http://127.0.0.1:5000`.

### 2. عبر سطر الأوامر (Terminal / PowerShell):
```powershell
# تشغيل واجهة الويب التفاعلية (الموصى به)
python run_tracker.py

# أو استعراض الدعاوى الحالية في التيرمنال مباشرة:
python run_tracker.py --list

# تحديث فوري مباشر من خوادم مصر الرقمية:
python run_tracker.py --refresh

# تشغيل وضع المراقبة المستمرة وإرسال إشعارات ويندوز في الخلفية:
python run_tracker.py --watch --interval 10
```

## 🔐 تسجيل الدخول وإدارة الجلسة

توفر الأداة طريقتين مريحتين للدخول دون الحاجة لأي إضافات:

### الطريقة الأولى: الدخول التلقائي عبر المتصفح (موصى بها)
- اضغط زر **«حالة الجلسة / تسجيل الدخول»** في واجهة الويب، ثم اضغط **«فتح المتصفح لتسجيل الدخول»** (أو شغّل `python run_tracker.py --login`).
- سيفتح المتصفح (Edge أو Chrome) على بوابة مصر الرقمية.
- بمجرد إدخال كلمة المرور والدخول، ستلتقط الأداة بيانات الجلسة (`accessToken` و `refreshToken`) تلقائياً وتغلق المتصفح.
- **التجديد التلقائي:** يتم تجديد الجلسة تلقائياً في الخلفية كلما اقتربت من الانتهاء دون إزعاجك.

### الطريقة الثانية: إدخال الرمز يدوياً
- يمكنك إدخال الرمز مباشرة من نافذة الجلسة أو عبر الأمر:
```powershell
python run_tracker.py --token "eyJhbGciOi..."
```

## 🌟 المزايا والوظائف الرئيسية

1. **واجهة تحكم حديثة باللغة العربية (Dashboard):**
   - شرائح تصنيف سريعة (تقدير ودفع الرسوم، تم التقدير، تم الدفع، تحت المراجعة، قيدت بالجدول، إبلاغ المحامي، غير مستوفي، مسودات، ملغاة، بدون اسم).
   - بحث فوري باسم الموكل، رقم الطلب، أو رقم السداد.
   - نسخ فوري بضغطة زر لأي رقم طلب أو رقم سداد.
   - تعديل أسماء الموكلين مباشرة في الجدول مع حفظ فوري محلي.

2. **نظام التنبيهات وإشعارات ويندوز:**
   - إشعارات منبثقة أصلية على Windows 10/11 عند:
     - رصد طلب جديد.
     - تغير حالة أي دعوى (مثلاً: من تقدير الرسوم إلى دفع الرسوم أو القيد بالجدول).
     - تغير أو صدور رقم سداد جديد.

3. **سجل التدقيق (Audit Log):**
   - حفظ كامل لسجل كل انتقال في حالة الدعاوى وتوقيت حدوثه وبصمته الرقمية مع إمكانية تصديره إلى ملف JSON.

4. **توليد ملفات الأدلة الرقمية (Evidence Generator):**
   - توثيق دقيق لكل مرحلة ووقت حدوثها بتوقيت القاهرة.
   - حساب البصمات الرقمية المشفرة SHA-256 للاستجابات الأصلية.
   - دليل المطابقة مع إشعارات البنك وكشوف الحساب لتبيان الخصم الفعلي.
   - إمكانية تحميل ملف JSON أو فتح تقرير HTML منسق جاهز للطباعة.

5. **المطابقة البنكية (Bank Reconciliation):**
   - جدول يجمع كل الدعاوى التي صدر لها أرقام سداد مع تواريخ الدفع الدقيقة المسجلة لدى المنصة.

6. **النسخ الاحتياطي والاسترجاع لأسماء الموكلين:**
   - متوافق 100% مع ملفات النسخ الاحتياطي الخاصة بالإضافة السابقة (`case-names-backup.json`).

## 🛠️ دليل أوامر السطرية (CLI Cheat Sheet)

| الأمر | الوصف |
| :--- | :--- |
| `python run_tracker.py` | تشغيل واجهة الويب في المتصفح |
| `python run_tracker.py --list` | عرض جدول الدعاوى المحفوظة محلياً |
| `python run_tracker.py --refresh` | جلب آخر تحديث فوري من المنصة |
| `python run_tracker.py --watch` | مراقبة مستمرة في الخلفية مع إشعارات ويندوز |
| `python run_tracker.py --login` | بدء نافذة المتصفح لتسجيل الدخول والتقاط الجلسة |
| `python run_tracker.py --status` | استعراض حالة الجلسة وصلاحية التوكن |
| `python run_tracker.py --set-name <رقم_الطلب> "<الاسم>"` | تعيين اسم موكل لدعوى معينة |
| `python run_tracker.py --evidence <رقم_الطلب>` | استخراج ملف تقرير الأدلة الرقمية والبصمات |
| `python run_tracker.py --reconcile` | عرض جدول المطابقة البنكية لأرقام السداد |
| `python run_tracker.py --audit` | استعراض سجل التدقيق الزمني للتغييرات |
| `python run_tracker.py --backup names.json` | تصدير أسماء الموكلين إلى ملف |
| `python run_tracker.py --restore names.json` | استرجاع أسماء الموكلين من ملف |
